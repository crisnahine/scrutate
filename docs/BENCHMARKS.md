## Caveats (read these)

- 11 logical cores. Multi-threaded tools (scrutate, ripgrep, ugrep, git grep) scale with cores; grep, ack and ag search one file at a time.
- The corpora are Python-only; the byte-level search cost does not depend on the language, but structural-search and indexing figures do.
- Rows where scrutate is slower are in the tables like any other. docs/LEADERBOARD.md has the statistical comparison (30 runs per tool, confidence intervals) on more corpora; this page adds memory, start-up, concurrency and index costs.
